## Sobre mim

Sou desenvolvedor Full Stack Sênior com foco em desenvolvimento web. Trabalho na construção e evolução de aplicações, conectando interfaces, serviços e bancos de dados às necessidades do negócio.

Minha atuação inclui aplicações corporativas, integração com ERP e recursos de inteligência artificial. Tenho atenção especial às regras de negócio, à manutenção do código e à segurança no acesso às informações.

Além do desenvolvimento web, utilizo React Native e Kotlin em desenvolvimento mobile e Python para automações e soluções de apoio.

## Frentes de atuação

- **Desenvolvimento full stack:** construção de interfaces e serviços, integração entre front-end e back-end e implementação de regras de negócio.
- **Integração de sistemas:** conexão de aplicações com APIs e ERP, com atenção à consistência dos dados e às permissões de consulta.
- **Segurança de aplicações:** autenticação multifator, gestão de sessões, controle de acesso e registros de auditoria.
- **Inteligência artificial aplicada:** integração com provedores de IA e desenvolvimento de controles para o uso de dados em aplicações corporativas.
- **Evolução de software:** investigação de falhas, manutenção de funcionalidades e validação de alterações com testes de regressão.
